Updated version of the Simonides' RK 1.42 HD Game Settings 

HD Launcher helps you to set up the game. It can edit some hidden game settings, such as resolution (up to 1920 x 1080) or language, along with more common ones such as sound, particle system etc.

It is recommended to install Settings.exe on 1.42 RK (check our discord for newest patch), however you can try to run it with older versions as well.

To install HD Launcher v2 on 1.42 RK, just download the Settings.exe from the releases and copy it into the game folder, replacing old Launcher (for steam version it is usually ...\Steam\steamapps\common\Rising Kingdoms).

If you want to install HD Launcher v2 without 1.42 you might need to download Source Code zip file and copy it into game folder as well. 
Still, be aware that it contains updated vxConst.ini (for latest 1.42), so your old version may be non-compatible with same old version for multiplayer, 
unless all players in the looby will have same SIM values in vxConst.ini ...
